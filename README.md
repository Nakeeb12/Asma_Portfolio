# Asma_Portfolio

Personal portfolio website for **Fathima Asma Mohamed Thaha**, psychology graduate from Felician University (Edison, New Jersey).

A static site in plain HTML, CSS and JavaScript, with no build step or dependencies.

## Features

- Responsive layout from phone to desktop
- Light and dark themes that follow the system setting, with a manual toggle
- About, strengths, experience timeline, education, honors and languages
- Works without JavaScript and respects reduced-motion settings

## Run locally

```bash
python -m http.server 5500
```

Then open http://localhost:5500.

## Deploy

The site is live at https://nakeeb12.github.io/Asma_Portfolio/ and hosted on GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
